## Priority Issues

- **[P1] Font variables overridden.** Body renders system-ui; the Inter/Noto Sans Bengali investment is invisible. Fix: delete the `:root` font fallback block; keep stack-level fallbacks.
- **[P1] Status colors used as text colors.** Amber/green/red text and white-on-color fills fail AA (2.1–4.4:1). Fix: ink text on colored fills; darker text-only tokens for on-paper status text.
- **[P2] Detector slop: 3× side-tab borders on landing cards.** Fix: replace with dot+label chips.
- **[P2] Mobile: 9px overflow + 32px tabs.** Fix: contain the tab strip (min-w-0), bump tab height to ≥40px.
- **[P2] Raw API codes as UX copy.** Fix: map detail codes to plain sentences in lib/api.ts.
- **[P3] Ghost elevation on MessageBubble; unthemed selection/caret/scrollbar; no keyboard shortcuts for the conversation list.**
